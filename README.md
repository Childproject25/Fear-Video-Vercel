# فيديو الخوف التفاعلي — نشر على Vercel

مشروع جاهز للنشر على Vercel يحوّل فيديو "أنا الخوف" إلى فيديو تفاعلي حي: يتوقف تلقائيًا عند نقاط محددة، يجيب الطلاب من هواتفهم عبر رمز QR، وتظهر النتائج فوريًا على شاشة الميسّر.

## محتويات المشروع

```
├── index.html        الصفحة الكاملة (تتضمن الفيديو نفسه مضمَّنًا داخلها)
├── api/store.js       دالة خادم بسيطة (Serverless Function) لتخزين إجابات الطلاب ومزامنتها لحظيًا
├── package.json       يحدد اعتماد المشروع على مكتبة @upstash/redis
└── README.md          هذا الملف
```

خلافًا لنسخة Claude Artifact، هذه النسخة تحتاج قاعدة بيانات صغيرة (Redis) لتخزين إجابات الطلاب لحظيًا بدل الاعتماد على تخزين Claude الداخلي — وهذا ما تؤمّنه لك Vercel مجانًا في دقيقتين كما هو موضح أدناه.

## خطوات النشر (أول مرة فقط)

### 1) أنشئ حساب Vercel (إن لم يكن لديك)
اذهب إلى https://vercel.com وسجّل حسابًا مجانيًا (يمكن الدخول مباشرة عبر GitHub).

### 2) ارفع هذا المجلد كمشروع
أسهل طريقتين:

**الطريقة أ — عبر الموقع مباشرة (بدون سطر أوامر):**
1. ارفع محتوى هذا المجلد إلى مستودع جديد على GitHub (اسحب الملفات في صفحة "Create repository" على github.com).
2. من لوحة Vercel: **Add New → Project**، ثم اختر المستودع الذي رفعته.
3. اترك الإعدادات الافتراضية (سيكتشف Vercel المشروع تلقائيًا) واضغط **Deploy**.

**الطريقة ب — عبر سطر الأوامر (Vercel CLI):**
```bash
npm install -g vercel
cd اسم-هذا-المجلد
vercel
```
اتبع التعليمات التي تظهر (تسجيل الدخول، تأكيد اسم المشروع)، ثم:
```bash
vercel --prod
```

### 3) اربط قاعدة بيانات Redis (خطوة ضرورية للمزامنة الحية)
1. من لوحة تحكم مشروعك على Vercel، افتح تبويب **Storage**.
2. اختر **Create Database** أو **Browse Marketplace**، وابحث عن **Upstash — Redis**.
3. اربطها بمشروعك (Connect Project). ستضيف Vercel تلقائيًا متغيرات البيئة اللازمة (`KV_REST_API_URL` و`KV_REST_API_TOKEN`) لمشروعك.
4. أعد نشر المشروع مرة واحدة بعد الربط حتى تُقرأ المتغيرات الجديدة: من تبويب **Deployments** اضغط على آخر نشر ثم **Redo Deployment**، أو نفّذ `vercel --prod` مجددًا.

هذه الخطوة مجانية ضمن الباقة المجانية لكل من Vercel وUpstash، وتكفي حاجة استخدام صفّي عادي بسهولة.

### 4) جرّب الرابط
افتح الرابط الذي يعطيك إياه Vercel (مثل `https://اسم-مشروعك.vercel.app`) — هذا هو نفس الرابط الذي سيظهر تلقائيًا كرمز QR على شاشة الميسّر لمشاركته مع الطلاب.

## طريقة الاستخدام في القاعة

١. افتح رابط المشروع على جهاز العرض واختر **«أنا الميسّر»**.
٢. اطلب من الطلاب مسح رمز QR الظاهر تلقائيًا بكاميرا هواتفهم، ثم اختيار **«أنا مشارك»**.
٣. شغّل الفيديو؛ يتوقف تلقائيًا عند 4 نقاط مرتبطة بنواتج التعلم الثلاثة، وتظهر نتائج تصويت الطلاب حيًا قبل الكشف عن الإجابة الصحيحة ومتابعة الفيديو.
٤. في النهاية اضغط **«إنهاء الجلسة وعرض الملخص»** لعرض ملخص أداء الصف.

## ملاحظات تقنية

- **لا حاجة لأي ملف فيديو منفصل**: الفيديو مضمَّن بالكامل داخل `index.html` (بصيغة base64)، لذلك حجم الملف كبير نسبيًا (~2 ميغابايت) لكنه يعمل من ملف واحد فقط.
- **إن ظهر تنبيه أصفر** أعلى الصفحة يفيد بعدم توفر المزامنة الحية: تأكد أنك أكملت خطوة "ربط قاعدة بيانات Redis" أعلاه، وأنك أعدت النشر بعدها.
- **الخصوصية**: تُخزَّن إجابات الطلاب مؤقتًا فقط (تُحذف تلقائيًا بعد 6 ساعات من إرسالها) ولا تتضمن أي بيانات تعريفية عن الطلاب.
- يمكنك تعديل نص الأسئلة أو توقيتها من مصفوفة `CHECKPOINTS` في بداية كود الجافاسكريبت داخل `index.html`.
